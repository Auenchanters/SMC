# SMC: soil-moisture survey simulator

A small rover drives the lanes of a simulated tomato field without touching the plants, probes
soil moisture, and rebuilds a moisture map with its uncertainty.

This Space is deployed from the SMC repository with `scripts/deploy_huggingface_space.py`.
Do not edit files here: the next deploy overwrites them.
